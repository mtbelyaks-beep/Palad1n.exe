# Palad1n (версия 2.0)

Бесплатное приложение для Windows: ищет малый бизнес без нормального сайта в 2ГИС, складывает в локальную базу, помогает писать по одному человеку. Автоотправки нет: чат открываешь и сообщение отправляешь ты.

## Запуск на Windows
Нужен Node 22.5+ и интернет для установки.
```
npm install
npm start          # запустить приложение
npm test           # тесты (ядро + сервис)
npm run shots      # проверка интерфейса в Chromium (нужен Playwright)
npm run dist       # установщик .exe (electron-builder)
```
Данные (база `leads.db`, `settings.json`) лежат в папке пользователя приложения (`%APPDATA%\Palad1n`; если раньше была база в `%APPDATA%\lead-finder`, приложение продолжает использовать её).

## Нейросети для текстов (новое в 2.0)
Настройки → «Нейросеть для текстов». Для каждого сервиса там пошаговая инструкция и кнопка со ссылкой на страницу ключей. Можно добавить несколько ключей: порядок задаётся перетаскиванием или стрелками, при отказе берётся следующий ключ. Когда не работает ни один, тексты берутся из шаблонов, а нейросеть возвращается сама, как только срок ожидания кончился. В очереди у каждого текста бейдж «шаблон» или «нейросеть · название ключа», в журнале отправок источник тоже записывается.
- Сервисы лежат в `main/providers.json`. Новый файл `providers.json` с большим `version` в папке данных заменяет встроенный, менять код не нужно.
- Ключи шифруются Windows (`safeStorage`) и хранятся в `ai.json` только в зашифрованном виде. Если шифрование недоступно, ключ не сохраняется. В журналы и в тексты ошибок ключи не попадают.
- Лимиты числами не зашиты: о них приложение узнаёт из ответов сервиса (429, Retry-After, «квота исчерпана») и считает свои запросы за день.
- GigaChat требует сертификат Минцифры: положи его в папку `certs` (кнопка в настройках).

## Входящие и аккаунты (новое в 2.0)
Вкладка «Входящие»: все аккаунты Telegram, WhatsApp и ВКонтакте, у каждого свой вход (отдельная сессия) и свой дневной лимит. Аккаунтов одного мессенджера можно добавить до шести. Рядом с каждым число непрочитанных (берётся из заголовка страницы мессенджера, например «(3) WhatsApp»), сумма видна на значке вкладки и в переключателе чата. Ниже список организаций, которым уже писали: с какого аккаунта, когда, этап можно сменить прямо там.
- В очереди приложение предлагает самый удобный канал по порядку из Настроек (по умолчанию Telegram, WhatsApp, ВКонтакте); если лимит канала кончился, предлагается следующий. Канал и аккаунт можно переключить вручную, выбранный аккаунт и канал записываются в журнал отправок.
- «Считать новые сообщения в фоне» открывает страницы мессенджеров скрыто, чтобы счётчики были живыми. Это тяжелее для компьютера, поэтому выключено по умолчанию.
- Первый аккаунт каждого мессенджера использует прежний раздел сессии, поэтому вход из версии 1 не пропадает.

## Сайты и предложение (новое в 2.0)
- Вкладка «Сайты» (кнопка «Сайт» есть и в карточке организации): шесть стилей в галерее с живыми миниатюрами, ниша по рубрике (барбершоп, красота, автосервис, стоматология, кафе, фитнес, ремонт, другое), блоки (услуги, о нас, отзывы, карта, контакты), свой цвет, просмотр на компьютере и на телефоне.
- Подставляются название, телефон, адрес, мессенджеры, рейтинг и карта. Отзывы не выдумываются: только настоящий рейтинг из 2ГИС и пустые заготовки.
- «Написать тексты нейросетью» просит заголовок, описание и услуги у твоей цепочки ключей; если нейросети нет, берутся тексты ниши. «Копировать промпт для нейросети» даёт готовое задание (ниша, стиль, данные, запреты на выдумки) для любого чата.
- «Сохранить сайт» кладёт один файл `index.html` в папку `sites` рядом с базой.
- «Предложение (PDF)»: страница A4 с пакетами, ценами, шагами работы и сроком действия; PDF лежит в папке `offers`. Цены и пакеты редактируются в Настройках. В стартовом наборе цены примерные: пока не включено «Цены мои», приложение предупреждает.

## Что внутри
| Папка | Назначение |
|---|---|
| `core/` | ядро `lead-core` (сбор 2ГИС, классификация, SQLite). Изменён один файл: `electron-engine.js` отдаёт окно как `engine.window`, чтобы показать его при проверке «я не робот» |
| `main/service.js` | вся логика между окном и ядром: сбор, фильтры, очередь, лимиты, чёрный список |
| `main/ipc.js` | таблица «канал → функция»; её же использует тестовый стенд |
| `main/main.js`, `preload.js` | Electron: окно, безопасность, мост |
| `main/templates.js` | шаблоны сообщений и подстановка |
| `main/sitegen.js`, `main/offer.js` | генератор сайтов (6 стилей, ниши, блоки, промпты) и коммерческое предложение |
| `main/ai.js`, `main/providers.json` | нейросети: ключи, цепочка, ошибки, запросы к GigaChat, Groq, OpenRouter, Gemini и «другому» сервису |
| `renderer/` | интерфейс (чистый HTML/CSS/JS, без сборки) |
| `test/` | тесты сервиса на подменной странице 2ГИС |
| `tools/shots.js` | стенд: настоящий сервис + интерфейс в Chromium, сценарии и скриншоты |

## Проверено и не проверено
**Проверено:** 33 теста ядра, 17 тестов сервиса, сценарии интерфейса в Chromium на настоящем сервисе (поиск, остановка, прокрутка колесом мыши на маленьком окне, анимация перехода вкладок, воронка с перетаскиванием, очередь, лимит, чёрный список, темы, лёгкий режим, пауза анимации), ошибок в консоли нет. Тест прокрутки проверен на поломке: со старым CSS он падает.

**Проверено владельцем на Windows (версия 1):** запуск в Electron, сбор с живого 2ГИС, правильность данных.

**НЕ проверено (в Electron на Windows; в Chromium-стенде проверены логика и вид):**
- счётчики непрочитанных: стенд подаёт событие смены заголовка вручную, а приходит ли настоящее число из Telegram Web, WhatsApp Web и ВКонтакте, зависит от них;
- фоновая загрузка скрытых страниц мессенджеров и несколько входов подряд;
- печать PDF скрытым окном Electron (в стенде PDF печатает тот же Chromium, файл и вид проверены);
- сохранение ключей через `safeStorage`.

**НЕ проверено (нейросети):** реальные ответы Groq, OpenRouter, Gemini и GigaChat. В проверочной среде эти сайты недоступны, поэтому цепочка, лимиты, ошибки и запросы проверены на подменных ответах (21 тест + сценарий в Chromium). Форматы запросов взяты из документации; названия моделей по умолчанию и условия бесплатных тарифов могли измениться: модель можно поменять в настройке ключа. Для GigaChat не проверена работа с сертификатом Минцифры и условия бесплатного тарифа для физлиц (Сбер меняет правила для новых клиентов).

**НЕ проверено:**
- **встроенный чат** (`<webview>`, `main/main.js`, `renderer/js/chat.js`): логика и вид проверены, но сам webview работает только в Electron. Откроются ли веб-версии Telegram, WhatsApp и ВКонтакте, не заблокируют ли они встроенный браузер, сохранится ли вход, не проверено;
- сборка установщика;
- подстановка текста: WhatsApp принимает `?text=`, для Telegram и ВКонтакте текст всегда кладётся в буфер, вставляешь сам.

## Перед публичной раздачей
Прочитай условия использования 2ГИС: правила сбора данных могут запрещать такое использование.

## Сборка exe
Двойной щелчок по `build.bat` (нужен Node.js 22+). В папке `dist` появятся `Palad1n-Setup-2.1.0.exe` (установщик) и `Palad1n-Portable-2.1.0.exe`.
Без Windows-компьютера: залить папку в GitHub, вкладка Actions, Build Windows exe, скачать артефакт.

## Сайты: редизайн шаблонов (2.0.1)
Шесть стилей теперь разные по вёрстке, а не по цветам: Aurora (светлый, плавающие карточки, bento), Noir (чёрный с золотом, вращающийся бейдж, нумерованный список), Bistro (арка, волна, наклонные карточки), Poster (жёлтый с чёрным, гигантские буквы, наклейка), Pastel (стекло и пузыри), Trust (сетка, панель фактов, полоса цифр). Добавлены иконки по нишам, бегущая строка, «как это работает», FAQ только из реальных данных, большой призыв позвонить, закреплённая кнопка звонка на телефоне. Только CSS и SVG, без скриптов, анимации отключаются при `prefers-reduced-motion`.
Промпт для нейросети переписан как бриф арт-директора: концепция до кода, арт-направление по стилю, мотивы ниши, проверка на скуку. Тексты в сайте не выдумываются: цены, отзывы и факты берутся только из данных 2ГИС.

## Что нового в 2.1
- **Ползунки и кнопки в настройках** теперь сразу показывают выбранное (была ошибка: после сохранения кнопка не перерисовывалась). Переключатели стали настоящими, с анимацией.
- **Фильтры парсера** разложены по строкам «Сайт», «Соцсеть», «Ещё», у каждой кнопки число организаций, внизу «Показано N из M» и «Сбросить». Выключены все варианты в строке «Сайт» значит «ничего не показывать», а не «всё».
- **Город и район** вводятся обычными словами: «Санкт-Петербург, Пушкин», «Москва Арбат», «Московский район спб». Код 2ГИС определяется сам. Для городов вне списка он подбирается по названию (это догадка, приложение об этом предупреждает).
- **Поиск только с нужной соцсетью:** выбери ВК, Telegram или WhatsApp (можно несколько), в базу попадут только такие организации.
- **Выбор соцсети вручную:** в карточке организации по кнопке на каждую доступную соцсеть.
- **2ГИС:** повторы при сбое, запасной адрес 2gis.com, обычный браузерный идентификатор, таймаут, код ошибки в сообщении. В настройках кнопка «Проверить соединение с 2ГИС» и поле «Свой прокси».
- **Анимации:** три уровня теперь отличаются. «Полные»: появление блоков волной, свет под курсором, кольца оценок, мерцание главных кнопок, пружинные переключатели, параллакс фона. «Спокойные»: только мягкое появление. «Выключены»: ничего.
- **Видео-обои:** Настройки, Оформление, Фон, «Видео». mp4 или webm, без звука, по кругу, затемнение регулируется, на паузе при свёрнутом окне.
- **Сайты из шаблонов:** анимации при прокрутке (появление блоков, параллакс, полоса прогресса, подчёркивания), на чистом CSS, без скриптов.
- **Промпт для нейросети** в два этапа: сначала сбор сведений о бизнесе (поиск или вопросы), потом концепция и сайт. У каждой организации своя композиция, шрифтовая пара и настроение, чтобы сайты не повторяли шаблоны приложения. Два режима: «Эффектный» (GSAP, Lenis, Google Fonts через CDN) и «Простой» (один файл без библиотек).

Не проверено в настоящем Electron на Windows: видео-обои, проверка соединения, прокси, диалог выбора файла, повторы 2ГИС (проверены тестами и в Chromium).
