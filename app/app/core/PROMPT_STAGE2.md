# Промпт для следующего чата: интерфейс приложения-парсера

Скопируй всё ниже в новый чат и приложи папку `lead-core` (или архив).

---

Ты помогаешь мне, Матвею (19 лет, Санкт-Петербург и Германия), сделать бесплатное приложение для Windows. Отвечай по-русски, честно, без лишних комплиментов. Если идея слабая или рискованная, скажи прямо.

## Что строим
Приложение для поиска малого бизнеса в России **без нормального сайта**, чтобы предлагать им сайты и Telegram-ботов. Это инструмент прежде всего для меня; возможно, позже буду раздавать его в своём Telegram-канале (возможно, за $10, но это не цель). Приложение бесплатное и ничего мне не стоит: каждый пользователь использует свои ключи.

Моя личная цель по заработку **не должна появляться в приложении** (никаких «прогресс к цели» и т.п.).

## Что уже готово
Папка `lead-core` (Node 22+, без внешних пакетов): сбор карточек 2ГИС через скрытое окно, классификация сайта, база SQLite, движок, 33 автотеста. Прочитай `README.md` и тесты, **не переписывай ядро без причины**. Запусти `npm test` и убедись, что всё зелёное, прежде чем строить поверх.

Ядро даёт для каждой организации: название, адрес, район, координаты, рубрику, рейтинг, число отзывов, число филиалов (признак сети), телефоны, почту, ссылки WhatsApp/Telegram/ВКонтакте/Max, класс сайта (`own/builder/multilink/booking/social/none`), уровень `hot/warm/cold`, лучший канал связи, оценку 0-100.

Важные находки: у «сайта» в 2ГИС часто лежит виджет записи (yclients, dikidi) или ссылка на Telegram-канал; номер телефона приходит полностью; у ~100% барбершопов в выборке есть телефон, у ~80% мессенджер. Не проверено: адаптер `electron-engine.js` в самом Electron, глубина листания выдачи, условия использования 2ГИС (юридический риск сбора: напомни мне прочитать их до публикации).

## Стек
Electron (Node 24 внутри) + HTML/CSS/JS, окно без лишних зависимостей, SQLite через `node:sqlite`. Сборка в один `.exe` установщик (electron-builder или аналог). Электрон-окно с 2ГИС скрытое, сессия в отдельном partition.

## Интерфейс (очень важно: красота — неотъемлемая часть)
Тёмный «стеклянный» стиль: боковая панель с иконками, вкладки сверху (Парсер / База / Сообщения / Чаты / Настройки), карточки лидов с плашками («Без сайта», «Только соцсети», «Слабый сайт»), иконки мессенджеров на карточке, чипы категорий, счётчики сверху, **анимированный фон**. Всё настраиваемое пользователем:
- темы (тёмная стеклянная, светлая, AMOLED, неон) и свой акцентный цвет;
- фон на выбор: анимированный, статичный, своя картинка, прозрачность и размытие;
- плотность карточек, размер шрифта, перетаскиваемые панели;
- командная палитра Ctrl+K и горячие клавиши;
- «лёгкий режим» для слабых ПК и пауза анимации при свёрнутом окне.
Таблицы живут внутри приложения (никакого Excel как основы; экспорт можно как дополнение).

## Функции (я одобрил всё это)
**Поиск:** профили поиска (сохранить «автосервисы СПб, рейтинг 4+, без сайта» и повторять), режим «только новое с прошлого запуска», дробление города на районы и ниши на синонимы (чтобы обойти лимит выдачи), выбор области на карте, ночной запуск с уведомлением Windows.
**База и лиды:** автоотсев сетей и франшиз (настраиваемый порог филиалов), воронка-канбан (Новый → Написал → Ответил → Договорились → Оплатил), чёрный список «не писать» (по номеру/id/организации), теги, цвета, заметки, напоминания «написать повторно через N дней», массовые действия, оценка лида.
**Сообщения:** очередь «по одному» (лид, готовый текст, кнопка открыть чат с вставленным текстом, отправляю я сам; **автоотправку не делать**: аккаунты банят), дневной счётчик («осталось 12 из 20»), 3-5 шаблонов под нишу, A/B шаблоны, заготовки ответов на возражения, тон сообщения.
**Генерация сообщений нейросетью:** в настройках список провайдеров (Gemini, GigaChat, OpenRouter, Groq и др.) со ссылкой и пошаговой инструкцией получения ключа у каждого (инструкции в **обновляемом файле**, не вшитые). Можно добавить несколько ключей: если один провайдер не ответил или кончилась квота, берётся следующий (порядок задаётся перетаскиванием); когда все лимиты исчерпаны, приложение уведомляет и автоматически переходит на шаблонный режим (и возвращается, когда лимит сбросится). Лимиты не вшивать цифрами, определять по ошибкам и локальному счётчику. На каждом сообщении бейдж «шаблон / нейросеть (какая)». Ключи хранить зашифрованно средствами Windows, не писать в логи. Учти: Gemini API может быть недоступен из России (регион), GigaChat работает из России и имеет бесплатный тариф для физлиц.
**Чаты внутри приложения:** встроенные панели с официальными веб-версиями Telegram Web, WhatsApp Web и vk.com/im (способ 1: просто показываем официальные страницы, сессия хранится только у пользователя), привязка к карточке лида (открыть чат с лидом и подставить текст), общие «Входящие» со счётчиками непрочитанных, автоматический выбор лучшего канала (порядок задаёт пользователь), несколько аккаунтов, у каждого свой дневной счётчик. Учти: WhatsApp в России блокируют поэтапно; безопасные холодные сообщения — порядка 10-15 в день на Telegram-аккаунт и 15-20 в WhatsApp.
**Сайты:** генератор макета сайта из блоков (шапка, услуги, отзывы, карта, контакты) + 6 стилей, подставляет название/телефон/адрес бизнеса, галерея стилей с превью; промпт для нейросети под нишу (блоки: база ниши + стиль + данные бизнеса); коммерческое предложение в PDF.
**Уникальные функции (одобрены):** «соседи-конкуренты» (находит рядом конкурентов с сайтом и подставляет аргумент в сообщение), мини-аудит как приманка (карточка в 2ГИС, активность во ВКонтакте, скорость сайта через бесплатный PageSpeed, PDF клиенту), сигналы боли в отзывах («не дозвониться», «нет сайта»: отзывы 2ГИС могут требовать ключ), радар новых открытий в районе и нише, кейсы, которые копятся сами, тренажёр переговоров (нейросеть играет владельца с возражениями), подсказка цены по моей истории сделок (только локально), лучшее время для первого сообщения по часам работы.
**Отвергнуто мной, не делать:** персональное видео-предложение, бот-витрина на моём сервере.
**Надёжность:** резервная копия базы одним файлом, мастер первого запуска из 3 шагов, проверка обновлений, понятные ошибки («источник не ответил, повтори через 5 минут»).

## Порядок работы (не бросайся делать всё сразу)
1. Версия 1: окно Electron, подключение `lead-core` через адаптер, вкладка «Парсер» (поиск, таблица карточек, фильтры), «База» (статусы, воронка, чёрный список), темы и анимированный фон, очередь сообщений с шаблонами. Сначала проверь `electron-engine.js` на живом 2ГИС.
2. Версия 2: чаты во встроенных панелях, нейросети с цепочкой ключей, генератор макета сайта и КП.
3. Версия 3: уникальные функции (аудит, соседи, радар, тренажёр), обновления, лицензии, если решу раздавать.
После каждой версии запускай тесты и показывай мне скриншоты. Если что-то не удаётся проверить у себя (например, нужен мой Windows), скажи это прямо, а не считай сделанным.
