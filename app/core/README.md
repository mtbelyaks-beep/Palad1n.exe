# lead-core — ядро данных парсера

Собирает карточки организаций из 2ГИС, определяет, есть ли у них нормальный сайт, достаёт телефоны и мессенджеры, оценивает лид и складывает всё в локальную базу SQLite. Интерфейса нет: это основа, на которую ставится приложение.

## Как работает
Приложение открывает **скрытое окно** с `2gis.ru` на компьютере пользователя и читает данные тех же страниц, что видит человек в браузере. Ключ API не нужен, лимит у каждого пользователя свой.

```
Engine.open(city, query) → pages() листает выдачу → fetchCard(id) → buildLead() → upsertLead() в SQLite
```

| Файл | Назначение |
|---|---|
| `src/page-scripts.js` | код, который выполняется внутри страницы 2ГИС (выдача, переключатель страниц, разбор карточки) |
| `src/classify.js` | классификация сайта (`own / builder / multilink / booking / social / none`), телефоны, мессенджеры, выбор канала, оценка 0-100 |
| `src/db.js` | база: статусы, заметки, чёрный список, кэш, фильтры. Статус и заметки пользователя не затираются при повторном сборе |
| `src/engine.js` | движок: листание, пауза с разбросом, кэш, отмена, прогресс |
| `src/electron-engine.js` | адаптер: скрытое окно Electron. **Не запускался**, проверяется на этапе интерфейса |

## Запуск тестов
Нужен Node 22.5+ (встроенный `node:sqlite`, пакеты ставить не надо).
```
npm test
```

## Классы сайта и «уровни» лида
- `own` — собственный домен → `cold` (нормальный сайт есть)
- `builder` (tilda, wix…), `multilink` (taplink…), `booking` (yclients, dikidi — только виджет записи) → `warm`
- `social` (только соцсети/мессенджеры), `none` (вообще ничего) → `hot`

2ГИС называет «сайтом» и виджеты записи, и ссылки на Telegram-канал, поэтому его фильтр «С сайтом» занижает число лидов. Здесь они сортируются отдельно.

## Что проверено, а что нет
Проверено: 33 автотеста (в том числе регрессии на две реальные ошибки, найденные на живом 2ГИС); прогон на 72 карточках барбершопов Петербурга; листание до 20-й страницы выдачи.

**Не проверено:**
- `electron-engine.js` внутри Electron;
- как глубоко 2ГИС позволяет листать выдачу (в Петербурге по барбершопам ~85 страниц; дальше 20-й не доходили);
- условия использования 2ГИС для такого сбора: **прочитать до публичного релиза и до первых продаж**;
- поведение при блокировке (капча, ограничение): движок это ещё не обрабатывает, только считает ошибки.

## Особенности данных
- Число «Места N» в выдаче зависит от видимой области карты: у одного и того же запроса бывало 1075 и 1022.
- В начале выдачи много рекламы и сетей; обычные бизнесы глубже.
- В данных страницы встречается `\'` (апостроф в названии): это не JSON, перед разбором такие места исправляются.
- Номер страницы берут из адреса: в переключателе с 7-й страницы появляется «…».
